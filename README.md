# Museum of Candy

A static landing page exercise focused on responsive layout, typography, imagery, and navigation.

## Interface

- Alternating image and text sections built with the Bootstrap grid.
- Responsive content ordering across screen sizes.
- A collapsible navigation menu.
- A fixed navigation bar that changes style after scrolling.
- Custom CSS and the Nunito typeface.

The page uses sample copy and navigation links. It does not provide ticket purchases or a content management backend.

## View locally

Open `index.html` in a browser. No package installation or build step is required.

The page loads Bootstrap 4.1.3, jQuery, Popper.js, and Google Fonts from external CDNs, so those assets need an internet connection.

## Files

| Path | Contents |
| --- | --- |
| `index.html` | Page markup, CDN references, and scroll behavior |
| `app.css` | Custom colors, typography, and responsive adjustments |
| `imgs/` | Page imagery |

This repository is a frontend learning exercise. It makes no claim to operate a real museum or own the third party libraries and imagery it uses.
